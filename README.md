# 🛡️ CyberShield – Password Security Analyzer

CyberShield is a beginner-friendly Python project. Today making a proper password is essential in order to keep our sensitive and personal information safe. This tool checks & analyzes password strength and identifies common password security risks.

## Features

- Password length checking
- Uppercase and lowercase detection
- Number and special character detection
- Password strength scoring
- Common password detection
- Name and birth year detection
- Repeated character detection
- Sequential pattern detection
- Security checklist
- Password improvement suggestions
- Masked password input

## Technologies Used

- Python 3
- maskpass library

## Installation

1. Install Python 3.
2. Install the required library:

```bash
pip install maskpass
```

## How to Run

Open the project folder in your terminal and run:

```bash
python main.py
```

## Project Version

Version 1.0

## Disclaimer

CyberShield is an educational project. Its password analysis uses basic security checks and does not guarantee that a password is secure.

Please Use dummy passwords for testing. Do not enter your real passwords.
